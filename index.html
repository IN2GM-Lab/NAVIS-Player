Features

Everything you need for
volumetric playback

A full-featured research-grade player built entirely on open web standards — no plugins, no native code, no server-side processing.

🌐

100% Browser-Native

Runs on WebGL + Web Workers entirely in the browser. Works in Chrome and Edge with no installation, no plugins, and no server-side rendering.

🔒

Local-First & Private

Pick a folder of .ply frames from your filesystem via the browser File System Access API. Your data never leaves your machine.

🚀

Parallel Streaming Engine

Web Worker-based PLY parser with configurable prefetch-ahead, keep-behind, cache cap, and concurrency — balancing latency against memory.

🎮

Dual Navigation Modes

Orbit for object-centric inspection. Explore for WASD/QE first-person flying with roll, boost, precision, and mouse-wheel speed control.

🎨

Rich Rendering Controls

Point size, downsample ratio, per-frame normalization, color modes (source / greyscale / mono), floor plane, and light/dark UI themes.

📊

Performance HUD

Optional dev overlay showing point count, frame index, parse/render timings, memory usage, HMD position/angle, and fly speed in real-time.

🎬

Full Playback Controls

Play/pause, single-frame step (±1 and ±10), loop toggle, variable playback speed, and a timeline scrubber for instant frame access.

💬

Subtitle Support

Load .vtt or .srt files and sync captions to frame index. Customize FPS mapping, position, font size, and color.

⚡

Open Source · Apache 2.0

Fully open source, freely available for research and commercial use. Contributions, issues, and pull requests are welcome on GitHub.

Quick Start

Up in 30 seconds

Serve the player locally, then pick your frames — no build step, no npm.

# Clone the repo
git clone https://github.com/IN2GM-Lab/NAVIS-Player.git
cd NAVIS-Player/viewer

# Serve with Python (or any HTTP server)
python3 -m http.server 8000

# Open in Chrome or Edge
open http://localhost:8000

# Then click "Choose folder" and
# select your .ply frame directory.

Getting Started

From clone to playback
in four steps

01

Clone the repo

Get the source from GitHub. No build system or package manager required.

git clone https://github.com/IN2GM-Lab/NAVIS-Player.git
02

Start a local server

Browsers block file:// Workers. Any HTTP server works — Python ships with one.

cd viewer && python3 -m http.server 8000
03

Open in Chrome or Edge

Navigate to localhost. The player loads instantly — no login, no account needed.

http://localhost:8000
04

Choose your .ply folder

Click Choose folder, select your frame directory, and press play. Frames are named sequentially: Name_0000.ply, Name_0001.ply, …
